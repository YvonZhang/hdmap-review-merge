# 审核规则及证据边界

## 两份业务规范

依据用户提供的《高精地图采集需求及详细要求及审核要求-20241118(1).docx》和《路口检测区绘制说明文档V1.1(1).docx》。本次完整文字摘录和图例位于项目 `依据摘录/`，方括号序号是 OOXML body 块号，不是页码。原始文件路径见 `zhangjiakou-context.md`。规范中的操作步骤只说明历史制作方式。

## 高精地图

| 项目 | 规范依据 | 自动化及人工边界 |
|---|---|---|
| 坐标与交付 | WGS84；每路口文件夹、每层一套 SHP/SHX/DBF/PRJ；最终同图层合并 | 查 PRJ 与数值，明确变换才重投影；CPG 必须与实际 DBF 编码一致，补 UTF-8 标签不等于转码 |
| 覆盖 | 路口全域、各向道路原则上双向延伸 250 m | 需要路口清单、中心/进出口定义和路网；包名前缀、轮廓数量不能证明覆盖 |
| 精度 | 大部分图层 10 cm；过街天桥、立交涵洞 1 m | 需要可靠控制点、测绘/影像资料；几何合法不代表达到精度 |
| 拼接 | 重叠区对齐、一致 | 完全重复可带台账去除；相似不相同、属性不同、接缝错位人工判断，不默认吸附/简化 |
| 路口轮廓 | 单个完整面，沿边界内边缘，末端合理垂直闭合，特殊断口延伸约 10 m 封闭 | 检查拓扑；“整个轮廓一个面”不等于全市合稿只有一个面，也不允许跨路口 dissolve 吞掉属性 |
| 标线线改面 | 6、7、9、12、17、21、23 七类改 `_pl` 面要素 | 对旧 `_ln` 报版本不符，不根据后缀伪造几何 |
| 停止线、虚实线 | 连续性、开口、斑马线处截断、路段停止线、掉头开口等 | 结合现场资料逐路口判定，不能依空的 width/type 推断 |
| 待转区 | `type=0` 车道线、`type=1` 停止线；同一待转车道二者 id 相等 | 此处 id 是关联键，不能强制每要素全局唯一或擅自重编号；示例属性表仍写 Line，与面版正文冲突，需核实 |
| 隔离带/导流岛/井盖 | 边缘与中心区、颜色、真实开口关系；间隔分别 20/20/10 cm | 不对任意嵌套多边形认定重复；字段不足时记录待验 |
| 导流区 26 | 文件名 `_ln`，包含要素文字写面，说明又写按每条线中线制作 | 作为规范内部冲突单列；不机械把后缀或一行文字视为唯一依据 |
| 印刷物与箭头 | 车道/待转区/辅路箭头入 33；路口中心等其他位置入 31/32，按颜色归类；相同符号形状一致 | 通过空间与影像判定；31b/32b 是历史面补充层，不是 2024 明列的主图层 |

2024 明列 23 个展示性层；参考 122 包实际为 26 层，增加历史公交站台 16、31b/32b 面补充。两者不是简单同名升级。assets 的目录用于名称和展示映射，不能把每个候选图层视为每个路口都必须存在；需要时在 manifest 的 `expected_layers` 中声明本批真实必交项。

## 检测区

- 仅机动车道，面要素；事件类别到达 1、进入 2、通过 3、驶离 4。
- LaneId 三位：首位方向（常规北东南西 1/2/3/4；多叉路从北顺时针）；第二位进口 0、出口 1；第三位沿行车方向从左到右 1、2、3……。现文档不定义十条及以上车道编码，不能自行扩位。
- 到达位于停止线前沿车道约 60 m；进入在沿行车方向过停止线后；通过在过停止线延长线后；驶离距停止线延长线约 60 m，并与到达并列。检测区沿行车方向长约 5 m、宽为车道宽。
- 先画进入/通过，反推到达/驶离车道号。展宽、直右等特殊情况按规范图例允许前后车道数量不同；以进入事件匹配 EOC 为关键。缺配对只能提示，不一律判漏画。
- 业务键为 **IntersectionId + LaneId + LaneEventDetectorCategoryId**。LaneId 在不同路口重复是正常现象；同一车道的不同事件也不是重复。
- 导出 GeoJSON 保留长字段 `LaneEventDetectorCategoryId`。DBF 字段短名需要明确映射，如实测 `LaneEventD` → 长名；不能假定所有截断字段都同义。脚本要求 manifest `field_map`，并校验类别 1–4。
- 两个数字字段导入后归一为字符串，保留原字段；ID 与字段冲突报错。不能根据文件先后顺序生成官方路口 ID，未核实的使用 local 数据集键并标待核验。

## 检查等级

自动阻断项：无法读取的输入、坐标基准未知或偏移坐标、缺必要配套文件/编码证据、无效或空几何、超项目范围、类型不匹配、事件字段非法、同业务键冲突、当前规范要求面而数据仍为线、必交层缺失、导出发生损失。

人工复核项：测绘精度、覆盖、开口/车道真实施画、接边、属性空值/零值、字段相异的重合要素、事件配对、实际行驶方向、沿车道距离、EOC 对应、样式实机渲染。

脚本的检测区最小旋转矩形 3–7 m、短边 ≥1 m、长边 ≤15 m，以及相邻事件质心直线距离 30–90 m，仅是异常筛查范围，不是规范新增的验收公差。检测区超出选定有效道路轮廓超过 1 m²也只提示版本/位置复核。

## 格式依据

- [RFC 7946](https://datatracker.ietf.org/doc/html/rfc7946)：GeoJSON 经纬度使用 WGS84、经度在前。旧带 crs 的数据先明确来源再转换；GCJ02/BD09 不能通过写 EPSG:4326 改变坐标实质。
- [GDAL Shapefile 文档](https://gdal.org/en/stable/drivers/vector/shapefile.html)：SHP 配套文件、PRJ、CPG 与 DBF 字段限制。当前工具采取显式短名映射，不依赖某个版本的扩展元数据恢复长名。
- [Mapbox Style Specification](https://docs.mapbox.com/style-spec/reference/)：source 与渲染 layer 分开；vector tile 的 source-layer 不可沿用到 GeoJSON 源。MineMap 专有属性和服务端资源仍以实际引擎验收为准。
